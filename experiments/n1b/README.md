## 实测结果

RTX 4090 / PyTorch 2.8.0，32×32 完整渲染后裁 8×8 ROI；1–24 个固定高斯、SH3、
快门 [0.3,0.7]、背景固定。每种随机方法 24 个 seed；预算 16 次完整 R。
Simpson 使用不超过预算的 15 次；线性 CV 使用 2 次拟合+14 次残差；自适应线性多项式 CV
使用 9 次拟合+7 次残差。N1b、单层 CV 和 proposal 均用模型参数建代理，不增加完整 R 调用。
代理构建及 proposal 的时间均计入。没有任何重建优化步。

|---|---:|---:|---:|---:|---:|
|单层运动细条|1.119e-7|1.530e-6|3.98e-10|0.000389|39.36 / 4.92|
|双层反向运动|1.877e-7|2.283e-6|1.61e-9|0.000399|26.75 / 3.57|
|三层|1.801e-5|2.484e-6|3.15e-9|0.0504|27.14 / 3.55|
|8 静态前景层+动态层|0.005445|3.228e-13|近零|1.363e8|27.44 / 3.62|
|16 层密集遮挡|1.791|3.577e-6|4.0e-12|9539|27.13 / 3.45|

静态负对照所有方法仅有舍入误差，N1b 额外耗时约 8 倍。上述时间是当前 Python/Torch 原型
实测，包含同步；没有用 CUDA 融合优化，固定 cap16 的空槽也产生开销，不能外推优化后性能。

参考使用同一未 clamp CUDA R 的 1025/2049 节点 Simpson 加密；非静态场景参考 RMS 变化
为 1.44e-9–7.80e-7。它是收敛检查而非严格误差上界；不根据接近参考误差底的微小差异排序。
**密集场景的巨大退化远大于参考误差。**没有把代理负值当 bug 后 clamp；残差中减去的 g
与解析 G 使用同一列表、顺序、背景及系数。

同墙钟没有另跑长预算搜索。JSON 给出每臂实测时间、MSE×时间，以及用实测成本计算的
IID 方差等预算估算（`iid_same_wall_variance_ratio`）；该估算不是分层 MC 或求积的理论保证。
例如双层对 uniform IID 的等预算估算比约 0.0030，但 16 点 Gauss 已同时更准、更快。
因此不能用“对普通 MC 降方差”宣称优于实际强对照。

梯度每场景使用 48 个共同随机时间，记录所有 raw 参数组的 R 与 R−g 一阶分支梯度方差。
双层时多数参数组下降；密集遮挡中均值/尺度等组放大数百至上万倍，静态前景遮挡中部分组
放大至 1e8。这是同样本梯度方差诊断，**不是训练损失收敛或 PSNR 收益**；也不是硬排序、
剔除、early termination 事件边界的完整数学导数。未进行完整模型梯度显存或反向等墙钟比较。

## 复查与修正

1. 对照 CUDA 源码核验双四元数、协方差条件化、SH3 原始均值方向、颜色下截断和像素中心 +0.5。
2. 所有 R 走同一 `diff_rasterize`，禁用增密统计；没有使用会 clamp 的 inference。
3. Gaussian 积分用 float64/log-CDF 尾部差分；近零指数用保留导数的级数。数值测试包括窄峰、
   双侧远尾、平坦极限、双层精确合成和密集负代理的积分抵消。
4. 候选列表 detached，连续参数重算保留链式；不同分块得到同一结果，cap 溢出有记录。
   修复零范数四元数在无效候选中引发 NaN 的潜在路径，添加回归检查。
5. CPU raw65 每组随机方向有限差分通过；CUDA 静态单层的值与全部参数组梯度匹配独立代理。
6. 修复 pulse-MC 不应计算未使用的 pair G 的计时污染，只复核相同场景/seed 的该对照。
7. 最终 6 项测试全部通过；源代码/配置/方法子模块与基线没有差异。

## 为什么停止，后续方向是什么

执行前在脚本中设定：静态前景/密集遮挡的残差方差比超过 4 即停止向重建训练扩展。
8 个预定有限诊断完成后触发 `STOP_BEFORE_TRAINING`；随后只做正确性复查与对照计时纠正，
没有扩场景、调参搜索、重新训练或改写原结果。

结论不是积分恒等式失效，而是 degree-2 遮挡截断在高 opacity 多层下把被遮挡的动态层放大，
导致残差值与梯度方差失控。静态前景层场景 R 本身几乎不随时间变化，因此其相对方差比尤其
大；绝对 MSE 也从接近零升至 0.0054，不能仅归咎于小分母。

如果之后继续研究，优先提出并验证更保守的**静态遮挡块精确合成/透射率保留**结构，或依据
有效层数/残差成本回退到简单求积；不要直接增加训练时长。代理的 GPU 融合、去除空槽和共享
几何计算可降低成本，但不能修复密集场景的统计退化。窄峰错开导致共享 proposal 失效的核心
优势，还需要更窄、节点可能漏采的受控条件才能充分验证；当前测试不足以证明该优势能战胜
Gauss 求积。上述只是由本轮证据支持的改进方向，未私自实现新算法或继续实验。

边界：自适应多项式对照是透明的低阶分段线性实现，不是完整复现 Crespo 论文代码；没有
真实曝光元数据验证、全 N=215 万规模测试、真实场景 PSNR/SSIM/LPIPS 或新训练结果。
小场景前向峰值 allocated 约 10–19 MiB，仅为诊断规模，不能当全模型资源结论。
