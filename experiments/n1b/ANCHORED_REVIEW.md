# 针对首轮结果的修正（2026-10-19）

结论：**多层遮挡的巨大方差退化已在原有受控场景中消除，但当前版本仍不具备优于 Gauss 求积的综合收益；不进入重建训练。** 原始代码/结果保留，新结果单独写入 `results/anchored.json`。

## 原因与具体改动

原代理是完整 alpha 合成在所有 alpha=0 处的二阶展开。高 opacity 多层条件下，
`1−Σα` 的前景透射率变负。这是原方案的适用范围问题，并非积分公式写错；简单 clamp 会破坏 g/G 一致性。

新 `AnchoredProxy` 将快门均分为 **8 个固定区间**，每段在中点 alpha 值 A 附近展开。
记完整局部合成 f、前方透射率 T_i、后方合成颜色 B_i，δ_i=α_i−A_i：

```
g = f(A) + Σ_i D_i δ_i + Σ_{j<i} H_ji δ_j δ_i
D_i = T_i (c_i − B_i)
H_ji = −(c_i − B_i) Π_{k<i,k≠j}(1−A_k)
```

中点 T/B 用完整 alpha recurrence 计算；H 以排除某项的 prefix/suffix 乘积计算，避免
在完全不透明层除以零。每段的 δ 项与 δδ 项仍可由 Gaussian 单项/乘积的解析积分组成。
积分在局部时间坐标平移系数：`a'=a+bc−dc²/2, b'=b−dc`，各段平均后得到 G。
没有用离散求积值冒充精确 G，没有拟合残差样本，没有 clamp。

静态层的 δ=0，因此静态层背景下只有一/两层动态 Gaussian 时，保留完整静态遮挡而不丢失
相关动态项；所有层动态时仍是近似，8 段减少每段 alpha 的变化，不宣称任意场景安全。
分段数预先固定为 8，没有用测试结果调参选最优。中点 alpha、T、B、D、H 的参数导数全部保留。

工程改动：只在新版删除所有像素都空的尾部列表槽；批量计算各段和 pair 积分；添加分层残差
采样臂。原始 N1b 仍可调用并同机重测，因此新旧耗时可以直接对比。

## 复查与停止边界

最终10项测试通过，新增检查覆盖：

1. 双层精确性、静态前景遮挡保留；
2. 密集场景分段解析积分与逐段高精度数值积分一致；
3. 完全不透明中点的值及有限梯度，验证未引入除零；
4. 静态前景和密集动态场景全部raw参数组的方向有限差分。

原始压力场景方差停止门槛已不再触发，脚本返回 `REVIEW_BEFORE_EXPANSION`，这不是训练批准。
考虑 Gauss 同调用更快且多数场景更准，本次复查决定**不扩大实验、不启动训练**。
下一步瓶颈已从遮挡截断转为完整投影误差、列表遗漏及代理构建成本；本次没有继续堆叠修正模块。
