# 窄脉冲与实际时间预算补测（2026-10-20）

**决策：STOP_NO_CONFIRMED_JOINT_ADVANTAGE。停止本轮实验，不实施第2项投影修改、第3项性能优化，也不启动训练。**

存在真实的前向积分收益，但没有确认积分与梯度同时稳定受益；不能把这些结果简化为“完全无收益”，
也不能据前向结果直接推进训练。原基线及此前原始结果均未修改。

## 实验协议

- 现有 RTX 4090 / CUDA renderer，32×32 全图渲染后裁8×8 ROI，线性RGB、固定快门[0.3,0.7]。
- 8个原生4D Gaussian，固定空间位置、窄时间寿命，分别覆盖ROI的8列。这样隔离时间积分问题，
  不混入尚未修改的透视运动误差；不是新增真实场景或训练。
- 时间标准差 sigma = **0.016、0.004、0.001**；峰值对齐与按列错开各一组；相位偏移 **−0.003/+0.003**，共12组。
- 逐像素总alpha曲线的峰时刻实测：对齐组跨度0，错开组约0.32012。保存了所有64个像素峰时刻。
  错开组是8个分离峰，不宣称已经构造连续平坦proposal；最窄组共同q范围约[0.25,47.31]。
- 对照：分层MC、Gauss求积、几何pulse proposal MC、单项解析CV、新版分段透射率N1b。
  除proposal重要性采样外，随机方法统一使用分层时间采样，避免将采样规则变化算作代理收益。
- **同调用：**每臂16次完整R。**同时间上限：**每次估计50ms，前向和反向分别校准调用数，
  校准不使用误差结果；计入列表、系数、解析积分、proposal、CUDA R和完整代理反向，前后同步CUDA。
- 调用数在误差seed开始前固定，保留时间余量；“同预算”指相同50ms上限，绝非每次恰好消耗50ms。
  JSON记录每次真实耗时、误差与超时情况，不将超时数据冒充合规胜出。
- 初测每组12 seeds，实际使用独立保存的结果文件 `results/narrow.json`，未覆盖旧结果。

### 梯度目标及参考

梯度比较使用固定随机空间/RGB权重的一个VJP，覆盖8个Gaussian的全部raw65参数，共520维。
标量目标不是训练MSE，而是曝光图像的线性投影；误差为520维梯度向量的平均平方差。
不是整幅图像的完整Jacobian，不把一个VJP外推为全部训练梯度表现。

参考积分使用已知时间剔除和逐ROI像素alpha阈值事件分段，各段4/8点Gauss加密；时间节点detach，
目标为同一CUDA后端的**期望分支AD**，不包含事件边界移动的数学导数。原代理的全部链式导数保留。
12组参考加密的最大图像MSE变化2.145e-14、梯度MSE变化7.334e-17；远低于下述主要差异。
阈值分段参考利用已知合成结构，只用来评测，不作为免费提供给某个方法的积分结果。

## 初测结果

下表是50ms上限实验中N1b/Gauss的MSE比，列出两个相位范围；小于1较好。
部分臂有偶发超时，正式筛选不把这些臂当严格合规胜出；精确耗时、调用数与逐次误差见JSON。

|sigma|峰值布局|图像MSE比|梯度MSE比|
|---|---|---:|---:|
|0.016|对齐|0.95–1.55|12.1–134|
|0.016|错开|5.58–7.95|56.1–399|
|0.004|对齐|5.39–569|0.00058–0.00141|
|0.004|错开|2.62–16.35|0.146–0.650|
|0.001|对齐|0.0715–0.0875|0.0000056–0.106|

固定16次调用时，较窄脉冲的N1b前向优势更明显；但相同时间允许简单方法使用更多渲染调用，
因此同调用优势不能替代实际时间结果。最窄错开组的单项CV图像误差还低于N1b，未显示pair的独立必要性。

## 独立128次复核：排查漏采罕见梯度残差

最窄对齐组初测有积分和梯度同时受益的迹象，故仅对这两个既有相位进行确认。
seed改为10000–10127，每臂128次；保持50ms上限，重新进行不依赖误差的调用数校准并保留更多余量。
没有调sigma、相位、分段数、proxy结构或其他算法参数来追求更好结果。

|相位|量|N1b平均MSE|Gauss平均MSE|N1b/Gauss|实测中位耗时 N1b/Gauss|
|---|---|---:|---:|---:|---:|
|−0.003|图像|4.729e-8|1.533e-6|0.0308|24.60/33.95ms|
|+0.003|图像|2.166e-8|1.533e-6|0.0141|32.26/35.15ms|
|−0.003|梯度|9.776e-6|1.691e-9|5782|31.67/30.69ms|
|+0.003|梯度|1.434e-4|1.691e-9|84816|33.07/29.94ms|

前向收益保留：N1b比同预算单项CV的平均图像MSE也低约15–31倍。
但梯度仅能承受1次残差反向，Gauss可承受约42次；窄峰附近偶发的大导数使均值误差激增。
N1b单次梯度MSE最大值分别为 **0.001246、0.01676**，12次初测漏掉了这些重尾事件。

对独立seed作配对bootstrap，比较N1b与每次重采样中最优简单对照的平均误差：

- 图像误差比95%区间约[0.043,0.102]、[0.022,0.045]；前向收益有支持。
- 梯度误差比区间约[0.139,17321]、[0.106,248219]；极宽，**没有支持稳定梯度收益**。
  这也意味着不能把本次均值放大倍数宣称为精确的总体倍率。
- 复核中N1b图像没有超时；+0.003梯度有2/128次超过50ms，Gauss两相位均无超时。
  因此除了梯度误差问题，该臂也没有满足严格逐次时间约束。

预设继续门槛是：两相位下图像和梯度均优于最强简单对照至少20%，且时间合规。
独立确认未通过；停止的原因不是仅仅某次计时抖动，而是梯度收益不稳定且出现大残差。
