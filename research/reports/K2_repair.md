# K2 exact early-stop deletion cache 修复

状态：`RESOLVED / COMPLETED`。

旧实现使用无 early-stop 的 suffix 恒等式。原渲染器在 `T*(1-alpha)<1e-4` 时不累积当前 Gaussian 并立即停止；删除更早的点会放行原先不可见的后续点，删除“触发停止但未累积颜色”的点本身也会改变输出。因此旧公式的 replay 最大像素差为 0.009549，64 个真实单删对照仅 61 个通过，最大相对误差 51.53%。

修复后，CUDA 对每个原先已接受的贡献者及 early-stop gate 做匹配 Gaussian ID 的精确反事实重放，使用与原 renderer 相同的 alpha floor/cap、背景与停止控制流。验证结果：

- replay 最大像素差：0（t=0、149）。
- 真实单删对照：64/64 通过。
- 最大相对误差：2.40445e-6。
- 正式 K2 key：`d5073d9d688b15063013e59bf67524819aa99f033b67c6e3f2d0967542788014`。
- C4×T24 共 96 帧，338×254；构建 261.569 秒，平均 2.721 秒/帧。
- 缓存 51,776,192 B，215,724 个点至少一次非零，peak allocated/reserved 316,510,720 / 413,138,944 B。

该修复恢复了 K2 的定义与真实删除语义，P02/P03 及其他 K2 依赖任务不再因代理无效而阻塞。代价是统计从 O(ray contributors) 的近似 suffix 变为更昂贵的精确反事实重放；缓存可复用，不能把冷启动时间隐藏在方法运行中。
