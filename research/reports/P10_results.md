# P10 消失后重现事件保护结果

状态：`NEGATIVE / NO_OPPORTUNITY / NOT_ADVANCED`。S0/M0、b=0.5、0FT；R0 从 P02 集合执行单调事件保护 repair，R1 为同一需求清单但不 repair 的 P02 对照。方法确定性，已验证 seeds 0/1/2 保留 IDs 不变，因此各评测一次。

K1 的 5% 相对活动阈值和至少两个采样间隔检测出 47,616 个 episode 需求、20,162 个重现点。按 episode K2 总误差取前 256 个需求（242 个点，其中 static 10、dynamic 246），16NN/持续可见性/C4 至少一相机 8px/DC RGB 0.1 过滤后 256/256 均有可行候选。

但这 256 个高风险需求在 P02 集合中已经全部由自身或合格邻居满足：`already_satisfied=256`、`repairs=0`、`infeasible=0`。因此 R0 与 R1 的最终 IDs 完全相同。

重现中心采用完整分辨率 32px 圆形区域，433 个可见相机-事件行中 R1−R0 MSE 精确为 0。固定 W 外最早五个重现中心为 t=39/52/65/91/104，并完成各自 ±2 帧、两开发相机合计 50 个相机-时间位置的共识 GT 诊断；两规则仍相同。

这不是事件代理无事件：事件数量充足且全部可行，而是 P02 已满足预注册的前 256 个硬需求，复杂 repair 没有新增约束价值。结果也低于 P03-max 的 27.395662 dB，PSNR 差 0.145242 dB、尾部 drop 差 0.275552 dB，故不支持“硬重现保护优于峰值聚合”。局限是结论仅适用于前 256 个需求、T24/C4 代理与给定邻域/阈值；不外推为所有重现事件都不重要。
