# CTG-GS 实现与测试记录（2026-10-29）

本轮按用户后续要求实现并测试代码，执行了小规模 CUDA 渲染和有限步合成场景优化，未开始真实数据集训练。此前 PROPOSAL_zh.md 和 REVIEW.md 保留为设计阶段历史记录，以本记录及 IMPLEMENTATION_REVIEW.md 为当前状态。

## 实现边界

`runtime.py` 调用安装好的 FasterGS4D 原生 CUDA 光栅器，冻结原始参数，提供双传感器相机/分辨率/曝光采样、独立正值热头、共用几何 offset。没有修改原生子模块。`data.py` / `run.py` 提供显式标定 manifest、训练视角审计、native raw prefix 导入、有限次事务、检查点恢复。

当前是固定拓扑、静态场景的后处理优化适配器，不是完整原生 Trainer callback；未适配 N1b 已学习的加速度残差、在线增密或完成动态场景验证。重排/裁剪工具有状态测试，但 runner 不启用它们。原生 RGB optimizer 保持冻结，不作为训练恢复处理。

## 测试驱动的结构调整

V1（engine.py）要求源视角的几何 G 和热外观 A 改善幅度匹配。在 seeds 0–2 的几何偏移/混合误差共 6 个正例中，每例 3 次尝试全部因源拟合无法匹配而拒绝，几何没有变化。详见 `results/v1_probe.json`。旧日志拒绝时 source gain 字段被默认零覆盖，但候选收益列表保留；最终代码以独立 candidate gain 字段修复日志问题。

V2（profiled.py）改为：

1. 仅用源视角固定 8 轮拟合热头，每轮对固定半径集合做实际前向线搜索。
2. 固定该热头，利用剩余误差搜索有界几何候选；源视角选出唯一候选后才读取 witness。
3. 独立训练视角要求候选相对“仅拟合外观”和“当前模型”均改善；witness 只否决。
4. 原生贡献渲染估计改变高斯的 RGB 投影区域，检验可靠支持、局部/全图损失及固定 anchor。
5. 接受时提交实际检验过的热头和 offset；拒绝时不改模型/梯度，计数器和首次建立的 anchor 可以变化。热头无持久 Adam 状态。

V2 放弃了原来的源拟合匹配归因，不是因果保证。有限热外观预算仍可能使几何吸收外观误差；独立视角和 RGB 检验只是降低风险。V1 先贪心选最大 G，再寻找匹配 A，没有枚举所有可匹配 G/A 对；部分 mixed 案例的小 G 可能匹配成功。因此测试只证明当前 V1 策略停滞，不能证明所有源拟合匹配策略都会失败。后续应补全配对搜索与固定热头基线。

## 控制实验

RTX 4090，Python 3.11，PyTorch 2.8，项目 `.conda/nerficg` 环境。每场景 20 个已知高斯；RGB guard 使用 3 个曝光相机样本和 0.25 增益，热图有独立分辨率/外参；每例 3 次事务。开发 seeds 0–2 后冻结结构，确认用 seeds 10–14。

| 确认条件 | 场景数 | 接受次数 / 尝试次数 | 未见 RGB 视角 PSNR 平均变化 |
|---|---:|---:|---:|
| 几何偏移 | 5 | 7 / 15 | +12.55 dB |
| 几何 + 热外观误差 | 5 | 14 / 15 | +17.20 dB |
| 仅热外观变化 | 5 | 0 / 15 | 0，模型不变 |
| 无误差 | 5 | 0 / 15 | 0，模型不变 |

额外 stress（seeds 10–12）：统一 0.5 热头冷启动的 3 个几何正例全部降低几何/RGB 误差；只移动热目标、保持 RGB 真值不变的 3 个负例，9 次尝试全部被 RGB guard 拒绝。详情和源文件哈希保存在 `results/` 下四组 JSON。

**这是同渲染器生成/评估、没有传感器噪声的合成机制测试，不能当作真实数据集涨点或 SOTA。** 大幅 dB 变化来自人为小场景偏移与近乎无噪声目标。确认集只是种子独立，构造分布相同；零 MSE 的 JSON PSNR 用 1e-15 下限得到 150，是数值哨兵。

## 工程验证与修复

测试覆盖实际 CUDA 渲染/梯度、曝光积分、热/RGB 梯度隔离、零权重旁路、拒绝时模型/梯度/RNG 保持、数据分割与相机/时间/噪声校验、物理基线、断开的 RGB mask、热位移负例、native prefix → manifest → 保存/恢复、恢复后一致事务、Adam 重排与非法重排原子性。最终测试数量和独立结论见 IMPLEMENTATION_REVIEW.md。

reviewer 推动修复了重排先修改模型再检查 foreign optimizer、FP64→FP32 后溢出漏检、V2 绕过共用阈值校验、V1 日志覆盖。共用校验现在包含有限阈值/时间戳、最少 witness 和支持像素。

原生几何有限差分在 eps=1e-4 的一例有约 6.5% 差异。reviewer 定位到一个像素跨越 native alpha=1/255 的裁剪边界；固定内部支持区域的差分一致。最终检查保留全图多步长及内部区域检查，不能声称光栅器处处可微。几何候选始终以实际前向损失进行线搜索。

## 仍需研究验证

本地 MSRS/M3FD 配对图像缺少方法所需的共享坐标系多视角标定，不能直接作为该 3D 算法的训练数据。尚无真实多视角 RGB-T 重建结果，也没有同预算 RGB-only、直接 thermal loss、强热外观模型、反事实路线适配版的完整消融；新颖性未确立，真实涨点有条件。

一次接受事务在小例中约 77 次光栅调用（曝光样本分别计数），成本不能外推至百万高斯。局部覆盖按改变高斯的投影并集计算，不是逐高斯可观测性证明。强遮挡、全暗 RGB、错误标定、复杂热场和曝光轨迹失配仍可能导致拒绝或误修正。
