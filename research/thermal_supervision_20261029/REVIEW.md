# CTG-GS 独立审查

审查日期：2026-10-29。审查角色：用户要求的独立 reviewer agent。对象为本目录提案、文献和评估协议，以及 `experiments/thermal_supervision/core.py` / `test_core.py`；同时核对 FasterGS4D 原生渲染、反传、密度控制及 N1b v4 的残差接入方式。没有启动训练、GPU 渲染或场景优化。

## 结论与评级

以下是研究判断，不是成功概率或已有实验成绩。

| 维度 | 评级 | 判断依据 |
|---|---|---|
| 技术可行性 | **中高，有条件通过设计审查** | 固定标定、一阶有限步、独立热外观和函数式候选绕开了现有光栅器不支持的梯度路径；但原生适配器、候选搜索、事务提交和数据加载尚未实现。CPU 算子正确不等于完整系统可运行。 |
| 新颖性 | **中低，尚未确立** | 热辅助暗光重建、共享 RGB-T 高斯、动态多模态建模及 G/A 反事实试探均已有直接先例。潜在差异集中于源拟合匹配后的跨视角迁移检验和实际 RGB 曝光保护；目前是可检验组合假说。 |
| 涨点潜力 | **有条件中等，证据不足** | 已有结构覆盖、RGB 较弱而热对比明显且标定准确时，可能改善边界和几何；保守 gate、热外观歧义、冻结拓扑和计算开销可能完全抵消收益。尚无重建结果支持任何 dB 承诺。 |

**建议进入下一阶段的数据审计和最小原生实现；不建议当前直接开始训练。** 本轮可作为“算法设计、参考算子、独立审查”交付，不能描述为已完成热监督系统、已确立新方法或已提升重建质量。

## 最强已有工作及贡献边界

- [Xu 等，ECCV 2024](https://arxiv.org/abs/2403.14053) 已直接研究 thermal + RAW 改善低光可见重建，补充实验包含 Thermal-GS。任务设定及“热红外能帮助暗光 GS”不能作为首创。
- [ThermalGaussian](https://arxiv.org/abs/2409.07200) 和 [ThermoSplat](https://arxiv.org/abs/2601.15897) 已覆盖共享多模态表示、热结构利用以及模态差异处理。简单增加热头和热 loss 的贡献有限。
- [Dynamic Thermal Gaussians](https://arxiv.org/abs/2609.24531) 已提出动态 RGB-T 共享几何、模态相关形变及高斯路由。不能把 4D 扩展本身包装为新颖性。
- **最强方法论近邻是 [Counterfactual Route Optimization for Gaussian Head Avatar Modeling](https://arxiv.org/abs/2610.09791)**：同一状态的几何、外观及联合路线有限步试探，再按实际效果选择优化偏好。CTG-GS 的 G/A 试探不是新的通用优化原理。该文的任务、控制器及 utility 与本设计不同，不能仅因相似就断言完全等价；但必须提供其核心路由机制的热场适配对照。
- [梯度相似度辅助任务门控](https://arxiv.org/abs/1812.02224) 和 [更新后损失重加权](https://proceedings.mlr.press/v80/ren18a.html) 也限制了“自动筛选有用监督”的宽泛创新主张。

本设计比单纯 thermal trust gate 更有研究价值的部分，是明确区分“几何解释”和“热外观解释”，并检查哪一种解释更能迁移到其他观测。源拟合匹配消除了部分步长混杂，却**不等于容量匹配或复杂度控制**：G、A 的维度、参数化、可见范围和条件数不同。新意成立仍需要 T3 对照、强 A 消融及热场负对照，而不能只看是否超过 RGB-only。

| 发现 | 严重性 | 复现与状态 |
|---|---|---|
| 有限大残差产生 `inf-inf=NaN`，gate 比较未拦截，可接受无改善候选 | P1 | 审查时用 `1e20` 的相同 before/G/A 重现了 accepted=True。现用 `hypot`、中间值检查和显式有限 gain 检查修复；回归通过。 |
| 曝光权重求和溢出，有限权重归一化成全零 | P1 | 两个 `3e38` 权重曾把全 1 观测平均成 0。现采用最大值缩放并检查转换后数值；对应 float32 回归通过。 |
| noise 可以广播出更高秩，悄然改变损失维度 | P2 | 现只允许广播到原预测形状；拒绝升秩的回归通过。 |
| proposal 的中间乘法可能溢出；未知标定默认可信 | P2 | 现检查中间值并稳定归一化；`Frame.calibrated=False` 默认拒绝未经标定的证据。 |
| 半精度大图的权重归一化溢出 | P2 | 补充检查曾发现 float16、256×256、全 1 权重时，`sensor_loss(1,0)` 返回 0，而 float32 返回约 0.4142136。现将 half/bfloat16 传感器运算及权重归一化提升至 FP32；数值一致性和梯度有限且为正的回归通过。 |

修复后的 gate 在 float32 测试覆盖内符合提案的基本接受规则；没有发现必须放弃方案的原理性代码障碍。注意这些结论只适用于参考模块。`route_tensors` 的 toy 测试不能证明原生反传没有写入密度统计，`calibrated=True` 也不能证明数据实际标定合格。

## 进入真实训练前仍需完成的工程条件

1. **真实渲染与梯度路径。** 原生 timestamp 是 settings 中的 float，反传对 settings 返回 None，并受 `once_differentiable` 限制。固定相机/时间及一阶候选是可实施选择；不能声称已经支持学习外参、曝光轨迹或二阶优化。需要检查真实 IR SH0 的尺度、通道 mean、背景和相机射线，验证热 G 只对热残差 leaf 求导、热 A 只对热头求导，RGB SH/opacity/时间支撑/密度统计均不受热事务更新。
2. **完整事务与身份一致性。** 目前 gate 接受的是调用者提供的图片，无法证明 before/G/A 来自同一状态、同一曝光核及固定遮罩。适配器应记录状态版本和候选来源，保证 witness 不参与 source 搜索。拒绝时需逐项验证模型、优化器矩、梯度、RNG、密度缓冲不变；接受时只提交指定残差。热头、残差、参考尺度及优化器状态必须跟随 prune/sort/cleanup，并能 checkpoint 往返恢复。
3. **约束实际执行。** `bounded_proposal` 只给每步归一化界；累计位移、固定 audit bank、锚点窗口更新规则及投影尺度约束目前仍在文档中。RGB anchor 不能在损失受损后任意重置。完整实现应支持零热权重严格回到同一 B1，防止隐藏分支影响基线。
4. **原生可见性缺口。** 当前光栅器没有现成 depth/alpha/Gaussian-ID 输出。固定 ROI 只能提供保守重叠，不能正确处理所有遮挡、玻璃和热反射。不可把未验证的可见性当成真实几何约束；初期应限制到材料与遮挡较简单的场景。
5. **算力与数值边界。** 32 MB 等容量数值以及前向次数公式属于账面估算，没有测量峰值显存或耗时。失败候选、A 路试探、曝光积分、热头拟合和 Python gate 的同步开销都需计入；损失及门控应采用明确的安全精度。

这些项目是后续实现与验证清单，不是本轮无训练设计交付必须伪造完成的部分。

## 科学可证伪性与数据限制

**跨视角支持不是几何可识别性证明。** 静止无边界平面上的移动热场 `T(x,t)=T0(x-vt)`，与平面沿切向运动但保留固定热纹理，可以产生相同热观测。RGB 若无纹理，则 thermal witness 再多也不能唯一判定物体运动。有限高斯模型还可能用位移补偿热头欠拟合、错误遮挡或辐射漂移。至少需要移动热斑负对照、稳定热材质的真实运动正例及更强时间热外观；强 A 消除优势时，应承认原结果主要来自 A 欠拟合。

**可靠 RGB guard 能限制部分损坏，但不能保证测试涨点。** 全局均值可能掩盖小区域受损；只在可靠亮区保护，不能直接保护目标暗区。完全没有可靠 RGB 支撑时拒绝是诚实的边界。冻结拓扑只能纠正已有覆盖，无法恢复 RGB prefix 已遗漏的结构；提案已正确明确这一限制。

数据路径应保持当前顺序：先审计 [MVTV 官方数据入口](https://github.com/XuJiacong/Thermal-NeRF)，仅使用符合双传感器标定及参考真值要求的静态夜间子集。其固定单应对齐不能被当作精确共光心射线；若原始数据缺少需要的标定，必须降级几何结论或改用合格采集。本地 MSRS / M3FD 配对图不能直接充当三维/四维重建基准。

[DTG 官方项目](https://github.com/LinLif1869/DTG) 的双视角动态数据存在明确协议限制：保留一台相机作测试，往往只剩一个训练热视角，无法再提供独立 viewpoint witness。不能借用正式测试相机来满足 gate。最低需两个有重叠、同步的训练热视角及独立测试相机；要求两个 witness 则需三个训练热视角。若只保留时间段，必须报告 temporal holdout，而非独立相机新视角结果。时间同步也不能只比较未经审计的 timestamp 数值。

## 我会如何判断是否值得继续

评估文件中的 B1、T1、T2、T3、C0–C4 和相同 wall-clock 控制是必要的，不能只保留 B0/C3 的好看比较。重点结果包括：

- 与同曝光模型的 RGB-only、普通固定 thermal loss 及便宜梯度门控相比，RGB 测试 PSNR/SSIM/LPIPS 是否改善；不存在深度真值时不把 RGB PSNR 当几何精度。
- 匹配 source fit、加入 witness、增强 A 后是否仍有独立收益；G/A 路由适配 T3 能否同样达到效果。
- 移动热斑、热反射、错位/不同步及错误配对是否使 gate 按预期拒绝，错误接受是否伴随实际几何漂移。
- 暗区和模糊区表现、接受率与拒绝原因、累计位移、失败候选成本；相同时间预算下的收益是否仍存在。
- 场景级确认集、配对种子及不借用测试图的初始化/超参选择。前向比较用到的 witness 是优化数据，不能再宣称统计意义上的独立 cross-fitting。

文档中 +0.2 dB / +0.1 dB 是可预声明的工程推进目标，不是预期成绩，也不能代替以上机制证据。若只超过 RGB-only 而不超过普通 thermal 联合训练，结论应是“热数据有用”，而非“本监督选择规则有效”。若负对照发生持续几何漂移、接受率极低或同时间收益消失，应修改或停止扩展该 gate。
