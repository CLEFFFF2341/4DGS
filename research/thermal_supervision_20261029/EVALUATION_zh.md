# 数据、消融与执行门槛（尚未训练）

## 数据可用性

| 数据 | 本地/公开状态 | 能支持的结论 | 当前缺口 |
|---|---|---|---|
| 本地 MSRS / M3FD Fusion | 上轮已下载、解码及配对校验通过 | 2D配对读取、loss与错位敏感性检查 | 无可直接使用的多视角标定/曝光序列；禁止当3D/4D重建基准 |
| [MVTV](https://github.com/XuJiacong/Thermal-NeRF) | 作者提供下载入口，本轮未下载检查 | 优先做静态夜间可见光NVS；有长曝光参考的子集用于RGB指标 | 需审计RAW/长曝光配对、SfM初始化来源、真实K/外参、单应warp误差；它不是现成动态去模糊真值 |
| [RGBT-Scenes](https://thermalgaussian.github.io/) | 官方论文/项目可查，本轮未下载 | 静态多模态基线、反射/对齐鲁棒性 | 不能默认所有场景是夜间或有清晰RGB恢复GT |
| [DynamicRGBT-Scenes](https://github.com/LinLif1869/DTG) | 作者提供12场景及下载入口，本轮未下载 | 动态RGB-T研究的强候选 | 仅双视角、手动同步与共享位姿近似；保留一视角测试后可能只剩一个训练视角，无法满足本方法独立thermal witness |

两训练热视角 + 一独立RGB测试视角，是动态新视角协议的最小布局；若要求两个witness，需要三训练热视角。DTG若无法满足，不能偷用其测试相机作witness。可在两相机都训练时仅做预留时间验证，但必须称 novel-time / temporal holdout，不能冒称独立相机NVS。真正动态去模糊阶段需要追加合格采集或新数据。

原始数据入场审计必须输出：逐图camera/view ID、world-to-camera约定、K与畸变、timestamp单位、RGB/IR曝光核、同步残差、有效重叠域、热图是否AGC/伪彩/辐射标定、RGB黑电平与线性化、初始化与pose使用了哪些视图。只有同名文件或同分辨率不能通过。

## 三条评价线

1. **静态夜间主线**：MVTV合格场景，用低光RAW训练、可用长曝光参考评价。统一曝光/白平衡/色调映射；不得为每个方法在测试图上拟合增益或对齐。先确认静态、曝光差异不会带来运动/遮挡真值错配。
2. **受控退化机制线**：对具有真实sharp RGB-T、多视图标定和充分时间采样的数据，仅退化训练RGB；噪声在近似线性域注入，运动模糊由已知相机轨迹或真实相邻时刻曝光积分产生。保留sharp RGB仅用于独立评价。二维高斯滤波不是相机/物体运动曝光，不能替代主去模糊测试。禁止从RGB生成“假热图”再当独立传感器证据。
3. **真实动态扩展**：满足训练witness及独立测试视角后，再加入N1b v4及动态热外观。无同步sharp GT时只报告观测重投影/新视角质量、时序一致性与定性结果，不声称真实去模糊提升。

主目标是RGB测试PSNR/SSIM/LPIPS。热指标只作辅助。若没有深度/表面真值，不能从RGB PSNR上涨推出几何准确率上涨；几何结论需要已知合成场景或独立深度。

## 先冻结比较对象

| ID | 方法 | 隔离的问题 |

| B0 | 当前原生 FasterGS4D，中点观测 | 历史参照，不作为唯一因果基线 |
| B1 | 原生 + 相同RGB噪声/曝光模型 | 去掉成像模型本身带来的收益 |
| B2 | N1b v4 + 相同成像模型 | 当前仓库已有结构的强控制；与B1分开报告 |
| T1 | B1 + 同热头、固定权重thermal联合几何loss | 只增加thermal信息的便宜基线 |

| C1 | G/A + source fit match，去掉witness | 排除仅source选步效应 |

## 负对照：证明没有把热场变化当几何

- 固定平面、改变热亮度/移动热斑；真实几何不变，统计接受率和中心/深度漂移。
- 移动物体、热材质稳定；真实几何变化，检查proposal在witness上的有效迁移。
- 玻璃/金属热反射、不同谱段遮挡；测试共享结构假设的失效。
- 对齐扰动：0 / 0.5 / 1 / 2 / 4 thermal pixels；时间偏差按真实帧周期归一化，不把不同FPS用同毫秒量比较。
- thermal随机配对/时间打乱/全常数图；若仍取得类似RGB增益，怀疑额外优化预算或正则效应。
- RGB全暗、无可靠guard；应拒绝，不允许空mask导致0损失后“通过”。
- IR清晰度劣于RGB、低热对比、非线性AGC；方法应该承认无热证据，而非硬推几何。

一个严格歧义例子：无边界静止平面上的 \(T(x,t)=T_0(x-vt)\) 与带固定热纹理的平面沿平面方向移动，可形成相同多视角热观测。RGB无纹理时不能识别真实运动。因此gate最多提供模型内证据，不能给物理保证。

## 防泄漏、预算和统计

- 场景级划分开发与最终确认；各场景内部再划分训练相机/验证相机/测试相机。尽量遵守官方split；未给split时在看到结果前固定ID清单及SHA256。所有witness、guard、A拟合都只读train。
- 主超参数只在开发场景/验证视图选定，确认前冻结；不得把反复使用的witness叫独立验证集。若初始化/pose涉及测试图，必须标注并让各组一致，优先改成train-only。
- 至少5个合格确认场景、3个配对种子；若数据不足，如实报告小样本证据。按场景聚合、区间估计也以场景为单位，不把大量连续帧当独立重复。
- 报同RGB更新数、同总render次数、同wall-clock三种口径；热事务包含失败候选、source搜索、A试探和guard的所有成本。容量、初始化、RGB采样、曝光点数、输入信息保持一致。
- 记录逐场景/逐种子PSNR、SSIM、LPIPS，暗区/模糊区指标、热像素覆盖、G/A源下降比、拒绝原因、接受率、累计位移、RGB守护损失、耗时、显存和高斯数。

建议预声明推进门槛（工程目标，**不是预测结果**）：在确认集相对B1平均PSNR ≥+0.2 dB、相对T1 ≥+0.1 dB，且总体SSIM/LPIPS不退化、至少4/5场景方向一致；相同时间预算仍有正收益。若仅超过B0或仅热指标提高，不算满足RGB质量目标。是否达到论文级新意还取决于T3、各消融及负对照，不能由这两个数值门槛自动推断。
